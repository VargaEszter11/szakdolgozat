Data export / import Feedback

Unlocked. To move data between environments: on the source environment, export a snapshot below; on the target environment, import that file. Importing always replaces everything currently in that environment.

1. Export data

Downloads a JSON snapshot of every table plus uploaded photo files from this environment.

2. Import data

This permanently deletes all existing data in this environment and replaces it with the contents of the selected file. This cannot be undone.
